*** 🚀 Salary Prediction using Simple Linear Regression **

- This repository contains a machine learning project that predicts an employee's Salary based on their Years of Experience. It utilizes the Simple Linear Regression algorithm to model the relationship between these two variables.

** 📊 Project Overview

- The goal of this project is to demonstrate how a linear relationship can be used to make continuous value predictions. The model analyzes a dataset of 30 observations to understand how salary scales with professional experience.

1. Key Features:
Data Exploration: Initial analysis of the relationship between experience and compensation.

2. Visualization: Graphical representation of the regression line against actual data points.

3. Performance Evaluation: Accuracy assessment using standard industry metrics.


* 🛠️ Tech Stack & Libraries
- Language: Python

- Libraries: * NumPy & Pandas: Data manipulation and analysis.

- Scikit-Learn: Model building and evaluation.

- Matplotlib: Data visualization.

* 📈 Model Performance
The model has been evaluated with the following results:

- R² Score: 0.896 (Explains ~90% of the variance)

- Mean Absolute Error (MAE): 6286.45

- Mean Squared Error (MSE): 49,830,096.85
